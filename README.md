# Made Noise — сервер заказов (MySQL)

Этот backend принимает заказ с сайта, сохраняет его в MySQL и присылает
уведомление в Telegram. Ниже — подробная инструкция, по шагам, без
пропусков.

## Из чего это состоит

```
server/
  server.js        сам сервер (принимает заказы, шлёт Telegram)
  db.js            код, который разговаривает с MySQL
  schema.sql       НАСТОЯЩИЙ SQL-файл — его нужно один раз выполнить в MySQL
  package.json     список библиотек, которые нужно установить
  .env.example     шаблон настроек — токены, пароли и т.д.
```

**Важно понимать разницу:**
- `server.js` и `db.js` — это код на **JavaScript**. Его запускает программа
  `node` на компьютере/сервере. Его никогда не вставляют в панель MySQL.
- `schema.sql` — это **SQL**. Вот его как раз и нужно вставить в панель MySQL
  (phpMyAdmin/Adminer) и выполнить — но только один раз, при первой настройке.

---

## Шаг 1. Установи Node.js

Если ещё не стоит:
1. Зайди на https://nodejs.org
2. Скачай версию **LTS** (рекомендованная) под свою систему (Windows/macOS)
3. Установи как обычную программу — next, next, finish
4. Проверь, что всё встало: открой терминал (в Windows — "Командная строка"
   или PowerShell, в macOS — "Терминал") и введи:
   ```bash
   node -v
   ```
   Если увидишь версию (например `v20.11.0`) — всё установилось.

## Шаг 2. Получи доступ к MySQL

Тут два варианта — какой у тебя есть:

**Вариант А — MySQL уже есть на хостинге сайта.**
Зайди в панель управления хостингом → раздел "Базы данных MySQL" →
создай новую базу, например `made_noise`. Хостинг покажет тебе:
хост (host), имя пользователя, пароль, имя базы, порт (обычно 3306).
Это именно те 5 значений, которые пойдут в `.env` на шаге 4.

**Вариант Б — хочешь потестировать на своём компьютере.**
Проще всего поставить **XAMPP** (Windows/macOS) — это программа, которая
разом ставит MySQL и phpMyAdmin:
1. Скачай на https://www.apachefriends.org
2. Установи, открой "XAMPP Control Panel"
3. Нажми **Start** напротив строки **MySQL**
4. Открой в браузере http://localhost/phpmyadmin — это и есть панель
   управления базой
5. Для локальной установки данные обычно такие: host `localhost`,
   пользователь `root`, пароль — пустой, порт `3306`

## Шаг 3. Создай таблицу — выполни schema.sql

1. Открой phpMyAdmin (свой, от хостинга, или локальный из шага 2Б)
2. Слева создай новую базу данных с именем `made_noise` (кнопка "New" /
   "Создать базу данных")
3. Открой эту базу → вверху вкладка **SQL**
4. Открой файл `schema.sql` из этой папки, скопируй **всё его содержимое**
5. Вставь в текстовое поле на вкладке SQL в phpMyAdmin
6. Нажми **Go / Выполнить**

Если всё прошло без ошибок — слева появится таблица `orders`. Это нужно
сделать один раз, повторно выполнять не нужно.

## Шаг 4. Настрой .env

1. В папке `server` скопируй файл `.env.example` и переименуй копию в `.env`
   (именно `.env`, без "example" на конце)
2. Открой `.env` в любом текстовом редакторе (Блокнот подойдёт) и впиши
   свои значения:

   ```
   MYSQL_HOST=localhost
   MYSQL_PORT=3306
   MYSQL_USER=root
   MYSQL_PASSWORD=
   MYSQL_DATABASE=made_noise
   ```

   (это пример для локального XAMPP; если база на хостинге — впиши то,
   что тебе выдал хостинг)

3. Там же ниже — настройки Telegram-бота, как их получить — см. следующий шаг.

## Шаг 5. Подключи Telegram-уведомления

1. В Telegram напиши **@BotFather** → отправь `/newbot` → следуй его
   вопросам (имя бота, юзернейм) → в конце он пришлёт токен вида
   `123456789:AAExample...`. Вставь его в `.env` как `TELEGRAM_BOT_TOKEN`.
2. Напиши своему новому боту любое сообщение первым (иначе он не сможет
   писать тебе сам — так устроен Telegram).
3. Узнай свой chat id: напиши **@userinfobot**, он пришлёт в ответ твой
   id — вставь его в `.env` как `TELEGRAM_CHAT_ID`.

После этого при каждом заказе тебе будет прилетать сообщение с составом
заказа, суммой и данными клиента.

## Шаг 6. Установи зависимости и запусти сервер

В терминале:
```bash
cd server
npm install
npm start
```

`npm install` скачает нужные библиотеки (Express, mysql2 и т.д.) — это
нужно сделать один раз (и потом ещё раз, если поменяется `package.json`).
`npm start` запускает сам сервер.

Если всё хорошо, увидишь в терминале:
```
Made Noise API running on http://localhost:3001
```
Сервер должен оставаться запущенным (окно терминала открытым), пока
сайтом кто-то пользуется — так же, как любая другая программа.

## Шаг 7. Свяжи сайт с сервером

В `script.js` на сайте есть функция `submitOrder()` — сейчас она просто
выводит заказ в консоль браузера (демо-режим). Замени её тело на:

```js
function submitOrder(order) {
  return fetch('http://localhost:3001/api/orders', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(order)
  }).then(res => {
    if (!res.ok) throw new Error('order failed');
    return res.json();
  });
}
```

Когда сайт и сервер окажутся на одном домене (в проде, не локально) —
поменяй адрес на относительный путь `/api/orders` вместо
`http://localhost:3001/...`.

## Как проверить, что всё работает

1. Убедись, что MySQL запущен (в XAMPP — зелёная строка MySQL) и сервер
   запущен (`npm start`, терминал открыт)
2. Открой сайт, оформи тестовый заказ
3. Проверь: пришло ли сообщение в Telegram? Появилась ли строка в
   таблице `orders` в phpMyAdmin (вкладка "Обзор" / "Browse")?

Если заказ не приходит — проверь, что терминал с сервером не выдал
красным текстом ошибку. Самые частые причины: неверные данные MySQL в
`.env`, MySQL не запущен, или забыл выполнить `schema.sql`.

## Подключение оплаты картой

Готовой оплаты «из коробки» тут нет — это отдельный шаг, потому что у
каждого платёжного провайдера свой процесс подключения (юрлицо,
проверка, договор). Когда сделаешь страницу оплаты, самый простой путь
для российского бренда — подключить агрегатора, который сам всё
оформляет с банком:

- **ЮKassa** (бывший Яндекс.Касса) — самый популярный вариант для
  небольших магазинов, есть готовый Node.js SDK
- **CloudPayments**
- **Тинькофф Эквайринг**

Логика одинаковая во всех трёх: сервер создаёт «платёж» на сумму заказа
и получает ссылку, куда редиректить покупателя. В `server.js` уже
размечено место (`// ---- Payment integration goes here ----`), куда
это добавляется. Когда решишь, каким провайдером пользоваться — пришли
мне, и я допишу конкретную интеграцию (нужны будут ключи API, которые
ты получишь после регистрации у провайдера).
